# Introduction to Git and GitHub

## Project Name
Simple Interest Calculator

## Project Description
This project is part of the Introduction to Git and GitHub learning assignment. It demonstrates basic Git and GitHub operations and provides a Bash script to calculate simple interest.

## Simple Interest Calculator

The calculator accepts three inputs:
- **Principal (P):** The initial amount of money.
- **Rate (R):** The annual rate of interest in percentage.
- **Time (T):** The time period in years.

### Formula

Simple Interest = (Principal × Rate × Time) / 100

### Example
- Principal: 1000
- Rate: 5%
- Time: 2 years
- Simple Interest: 100
